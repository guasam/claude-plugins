# claude-plugins

The `guasam` marketplace for [Claude Code](https://claude.com/claude-code) plugins. Each plugin lives in its own repo; this one just lists them.

```sh
claude plugin marketplace add guasam/claude-plugins
```

## Plugins

| Plugin | Install | What it does |
| --- | --- | --- |
| [cc-paste-thumbnails](https://github.com/guasam/cc-paste-thumbnails) | `claude plugin install cc-paste-thumbnails@guasam` | Shows pasted images as thumbnails above the prompt (macOS) |
